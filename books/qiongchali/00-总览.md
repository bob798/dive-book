# 《穷查理宝典》拆解 · 总览

> 彼得·考夫曼（Peter D. Kaufman）编，李继宏译，中信出版社。英文原版 *Poor Charlie's Almanack: The Wit and Wisdom of Charles T. Munger*（首版 2005，第三版收入大幅修订的"人类误判心理学"）。中信中文版首版 2016 年 8 月，另有 2017 珍藏版——内容是英文原版的全译本，含李录中文版序、芒格传记、投资理念及二十多年公开演讲。**本书是芒格演讲与文章的编选集，不是专著**：同一思想在多讲反复出现，引用必须标明"第几讲"，且区分"芒格原话"与"编者考夫曼/作序者的转述"。

## 一句话主线

**靠一张跨学科的"思维模型格栅"做决策，再用"反过来想"和"避开人类误判"两套排雷术守住下限——长期不犯大错，复利自然赢。**

全书不教你怎么赢，教你怎么**别输**：芒格毕生在收集各学科的"大道理"挂成一张网（lattice），用它检查每个决策；同时编一张"人类会怎样自欺"的清单（25 种心理倾向），决策前逐条排雷。书名 *Almanack*（年鉴/历书）致敬富兰克林的《穷理查年鉴》——这是一本"处世历书"，不是投资手册。

## 全书地图（一张网 + 两把铲）

```
思想层   多元思维模型格栅（跨学科 big ideas）        ← 决策的"操作系统"
           ↑
方法层   排雷术A：Invert,always invert（反过来想）
         排雷术B：人类误判心理学·25 种倾向 + lollapalooza  ← 两把排雷铲
           ↑
约束层   能力圈（circle of competence）——只在圈内挥棒   ← 系统的运行边界
           ↑
案例层   伯克希尔/喜诗糖果·可口可乐建模·学院派经济学批判·
         芒格本人的人生选择                            ← 论据样本
```

驱动一切的底层姿势是**避免愚蠢，而非追求聪明**：先用能力圈圈定可玩的范围，再用思维模型生成判断，最后用"反过来想 + 25 种倾向清单"做两道排雷，确认"这步会不会让我死"。

## 全书讲次结构（核对版，第三/四章十一讲）

| 讲 | 标题 | 拆解中的角色 |
|---|---|---|
| 一 | 在哈佛学校毕业典礼上的演讲 | 用"如何过痛苦人生"反讲——逆向思维的开篇示范 |
| 二、三 | 论基本的、普世的智慧（及修正稿） | 多元思维模型 + 能力圈的核心来源 |
| 四 | 关于现实思维的现实思考 | 用思维模型给可口可乐建模的实操案例 |
| 五 | 专业人士需要更多的跨学科技能 | 跨学科为什么必要 |
| 六、七 | 慈善基金投资实践 / 慈善圆桌早餐讲话 | 把模型用到机构决策 |
| 八 | 2003 年的金融大丑闻 | 激励机制与会计失真 |
| 九 | 论学院派经济学 | 单一学科的危害（"铁锤人倾向"重灾区） |
| 十 | 在南加大 Gould 法学院毕业典礼上的演讲 | 处世智慧总集、最广为流传的金句来源 |
| **十一** | **人类误判心理学** | **全书最硬核：25 种心理倾向 + lollapalooza 效应** |

> 版本提示：第十一讲是芒格 1995 年哈佛演讲的基础上，2005 年为本书**大幅扩写**而成。网上流传的"23 种""24 种"是早期演讲版；中信书定稿为 **25 种**。引用倾向条目以书为准。

## 阅读路线（三遍读法，按非虚构适配）

| 遍数 | 只做一件事 | 提示 |
|---|---|---|
| 第一遍 | 通读抓骨架：先看第十、十一讲，再回头补二、三讲 | 别陷进伯克希尔投资细节，那是案例不是方法 |
| 第二遍 | 只盯"排雷动作"：把 25 种倾向各压成一行"触发→反制" | 压不成一条反制动作的倾向，等于没读懂 |
| 第三遍 | 只做概念卡 + 人物对照表 | 以"能力圈外的高回报诱惑，要不要伸手"为对照锚点 |

## 一个前置提醒

这是**编选集 + 智者箴言体**，含两类风险：（1）**伪托语录泛滥**——中文互联网"芒格说……"句式大量为后人编造或张冠李戴（"铁锤人"那句其实源自马斯洛，芒格是引用民间谚语而非原创），引用前务必核对本书原文与讲次；（2）**幸存者与精英视角**——芒格是亿万富翁的事后总结，他的"能力圈""不轻易出手"以巨大本金和耐心为前提，照搬到职场小白身上要做转译。拆它的正确姿势：**取其排雷清单（思维模型 + 25 种倾向 + 逆向思维），验其引文（逐条核对讲次出处），慎用其精英姿态。**
