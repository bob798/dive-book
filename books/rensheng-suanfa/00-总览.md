# 《人生算法》拆解 · 总览

> 喻颖正（老喻，公众号"孤独大脑"，未来春藤创始人），中信出版社 2020。底本源自得到课程《老喻的人生算法课》（2019），书与课内容高度重合但结构有调整；得到电子书另有副题版《人生算法：用概率思维做好决策》，台版书名《人生算法：輕鬆跨越出身與運氣》。引用时注明出处是书还是课——课程音频文稿与成书文字常有出入。

## 一句话主线

**人生是概率游戏：对内把自己练成一个可复制的认知内核（九段心法），对外用概率思维通关十八个人生难题——赢靠算法，不靠运气。**

全书反复在做一件事：把"命运"这个玄学词拆成两个可操作的变量——**内核**（你那套不断重复的基本套路）和**重复**（让内核滚起复利）。书名即方法：人生可以被当成算法来调试。

## 全书地图（两翼 + 一个飞轮）

```
思想层   概率思维 / 概率权 / 内核 × 复利              ← 全书的"操作系统内核"
           ↑
方法层   A计划·九段心法（对内：升级自己这台机器）
         B计划·十八关（对外：应对世界的不确定性）      ← 两翼结构
           ↑
案例层   巴菲特·凯利公式·AlphaGo·泰德·威廉姆斯·
         概率权选择题·作者自身经历                     ← 论据样本
```

驱动一切的是**认知飞轮**：感知 → 认知 → 决策 → 行动，循环往复。九段心法练的就是让这个飞轮转得起来、转得快、转得久。

## 阅读路线（三遍读法，按非虚构适配）

| 遍数 | 只做一件事 | 提示 |
|---|---|---|
| 第一遍 | 通读抓骨架：九段是进阶链，十八关是难题清单 | 别陷进案例，案例多是二手转述 |
| 第二遍 | 只盯"算法"：把每段/每关压成一行 if-then 规则 | 压不成一行动作的章节，说明没读懂或它只是装饰 |
| 第三遍 | 只做概念卡 + 人物对照表 | 以"概率权选择题"（100 万 vs 50% 一亿）为对照锚点 |

## 一个前置提醒

这是**畅销书体非虚构**：核心框架（内核×复利、认知飞轮、概率权）是作者原创且扎实，但大量案例是对巴菲特、卡尼曼、塔勒布等人的二手转述，章节间有课程改书稿的注水感。拆它的正确姿势：**取其骨架（九段进阶链 + 概率思维），验其案例（引用前核对一手出处），弃其鸡汤段落。**
