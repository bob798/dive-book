# 05 · 事件链：全书时间线与"三个局"

> 多数人只记得王庙村一个局。其实全书有**三个局**，难度递增、性质不同：一个职场局、一个商业局、一个攻心局。三个局共用同一个内核——**按规律办事，让对方的文化属性替你完成剩下的工作。**

## 一、全书事件链（粗时间线，1990 年代中后期）

```
丁元英解散私募基金（替德国资本在中国股市获利，良心不安终止合同，
个人收益被冻结数年）
  → 经肖亚文安排隐居古城，穷到变卖唱片度日
  → 肖亚文托芮小丹"顺便照应"，二人相识相恋
  → 【局一】韩楚风正天集团总裁之争，丁元英指点"不争之争"
  → 芮小丹要礼物："在王庙村写一个神话"
  → 【局二】王庙村 / 格律诗 vs 乐圣（主线，见 01-故事层）
  → 做局前五台山问道（见 07-场景深拆）
  → 【局三】芮小丹审王明阳，丁元英递"文化密码"攻心（见 07）
  → 音响展掀桌 → 乐圣起诉 → 三人退股 → 肖亚文接盘 → 格律诗胜诉
  → 林雨峰坠崖；乐圣转而与格律诗合作，王庙村焊进产业链
  → 芮小丹执行任务重伤，自杀殉职；丁元英闻讯呕血
  → 刘冰持"档案袋"要挟未遂，跳楼
  → 丁元英离开古城
```

## 二、局一：韩楚风总裁之争（职场局 · 不争之争）

| 要素 | 内容 |
|---|---|
| 局面 | 正天集团老总裁遗愿提名韩楚风接任，但两位资历更深的副总裁虎视眈眈，硬争则三败俱伤 |
| 丁元英的指点 | **退出竞争**：不表态、不结盟、埋头做事，把竞争舞台整个让给两位副总裁 |
| 依据的规律 | 两强相争必互相消耗、互相暴露；董事会要的不是"赢家"而是"稳定的能干者"。让人性自己运转，你只需要不在场 |
| 结果 | 两位副总裁斗到两败俱伤，韩楚风以"没参与内耗的那个人"胜出 |
| 现实迁移 | 当竞争的裁判是第三方时，最优策略常常不是赢过对手，而是**让对手们在裁判面前互相定义** |

这一局是全书的"小样"：丁元英方法论的首次展示，成本几乎为零，全靠看清结构。

## 三、局二：王庙村神话（商业局 · 主线）

完整拆解见 [`01-故事层-拆局.md`](01-故事层-拆局.md)。在事件链里只标注它与另两局的区别：**局一借的是人性（争位者的贪），局二借的是市场（乐圣的成本结构与林雨峰的性格），局三借的是神学（王明阳的逻辑洁癖）。**

## 四、局三：审王明阳（攻心局 · 一把"文化密码"的钥匙）

| 要素 | 内容 |
|---|---|
| 局面 | 死刑已定的智囊型罪犯王明阳，精通法律与神学，深知开口无益，软硬不吃，零口供 |
| 约束 | 刑讯无效也不可用；利诱无效（他必死）；唯一入口是他**还要一个"说法"**——他需要自己的逻辑自洽 |
| 设计 | 丁元英给芮小丹递"柴火"：不跟他谈罪，跟他谈他赖以自洽的那套强盗逻辑和神学 |
| 攻击点 1 | 王明阳自辩"强盗是直接获取的强者逻辑"。芮小丹拆穿：强盗逻辑本质是**破格获取**，是不敢直面市场竞争的懦弱，恰恰是弱势文化的极端形态 |
| 攻击点 2 | 王明阳搬出神学，芮小丹用"窄门"反杀：靠天堂的引诱、地狱的恐吓去行善，是交易不是善；**"不因上天堂、下地狱的因果才有美德"，才进了窄门** |
| 终局 | 王明阳的逻辑体系被对方用更高一层的逻辑覆盖，他要的"说法"只剩一个出口——"如果你能给自己的灵魂找个归宿，这份笔录就是你的忏悔" |
| 现实迁移 | 说服一个聪明人，不是驳倒他的结论，而是**接管他的前提**：在他自洽的体系之上，给一个更完整的体系，让开口成为他自己的需要 |

## 五、三局合参

| | 局一 | 局二 | 局三 |
|---|---|---|---|
| 领域 | 职场权力 | 商业竞争 | 心理/神学 |
| 借的力 | 对手的贪 | 对手的成本结构与面子 | 对手的逻辑洁癖 |
| 丁元英的动作量 | 一句话 | 一年布局 | 一晚递话 |
| 共同点 | **自己不下场硬拼，设计一个让规律自动运转的结构** | | |

三局看完，"高人"的祛魅也就完成了：丁元英没有任何超能力，他只是**每次都先问"这件事的规律是什么、谁的文化属性会替我干活"**。这正是可以学的部分。
