# 《遥远的救世主》拆解 · 总览

> 豆豆，2005 年作家出版社。电视剧《天道》（2008，王志文/左小青）为其改编。拆解以原著为底本；电视剧台词传播度高可做引用素材，但有删改（尤其结局与审讯戏），引用前核对原著。

## 一句话主线

**丁元英在王庙村做的不是扶贫，是一场社会实验：用一个"杀富济贫"的商业局，验证他关于"文化属性"的判断——救世主不存在，能救人的只有"按规律办事"本身。**

全书所有人物和情节都是这个实验的变量。书名即答案："遥远的救世主"= 救世主永远不会来。

## 全书地图（三层结构）

```
思想层  文化属性 / 强势文化 vs 弱势文化 / 神即道      ← 实验要验证的"假设"
          ↑
人物层  叶晓明·冯世杰·刘冰·林雨峰·肖亚文·芮小丹…   ← 实验的"样本组"
          ↑
故事层  格律诗 vs 乐圣的商战事件链                    ← 实验的"操作过程"
```

## 阅读路线（三遍读法）

| 遍数 | 只做一件事 | 提示 |
|---|---|---|
| 第一遍 | 追情节，快速通读 | 别停下来抄金句 |
| 第二遍 | 只盯丁元英的决策点 | 每个决策问一句："他依据的规律是什么？" |
| 第三遍 | 只做人物对照表 + 概念卡 | 以"乐圣索赔 600 万"事件为对照锚点 |

## 一个前置提醒

这是**虚构作品**，丁元英的操作有"爽文"成分（见 `04-选题库` 的引用纪律）。拆它的价值不在模仿操作，在于看清**"按规律办事"与"期待救主"两种文化属性在同一压力下的分岔**——这部分是真的。
