# dive-book · 拆书仓库

> 一本书一个目录，统一框架拆解。拆书不是做摘要，是把一本书拆成**可复用的判断力素材**：主线、决策、人物样本、概念卡、内容选题。

## 拆解框架（五件套）

每本书固定产出五份文档：

| 文档 | 拆什么 | 产出物 |
|---|---|---|
| `00-总览` | 一句话主线 + 阅读路线 | 全书地图，防止拆散 |
| `01-故事层` | 情节当案例拆：目标 → 约束 → 设计 → 预案 | 决策点清单 |
| `02-人物层` | 同一事件下不同人物的反应对照 | 人物对照表 |
| `03-思想层` | 核心概念，每个配原文 + 现实例子 | 概念卡（≤5 张） |
| `04-选题库` | 书 × 格物社理念的交集 | 可直接写的内容选题 |

## 方法约定

- **一条主线原则**：先找到全书唯一主线，所有拆解挂在主线上，挂不上的素材丢弃。
- **三遍读法**：第一遍只追情节（快）；第二遍只盯主角决策点，每个决策问"他依据的规律是什么"；第三遍只做对照表和概念卡。
- **引用纪律**：分清"原文"与"流传语录"，引用必须核对原著；虚构作品要标注"小说设定"与"现实规律"的边界。
